Unity maze game: five hand-authored levels, NavMesh enemies, coins and an exit door.

01 Maze Generator Preview

Browser preview only: recursive-backtracker maze carving (same family of algorithm as MazeGenerator.cs, which is optional and not used by the five shipped levels). Pick a size and generate.

Click "Generate maze" to carve one.

02 Game Features

Hand-authored levels

Five fixed level scenes plus a main menu — layout is authored in the editor, not carved at runtime.

NavMesh enemies

Enemies pathfind on a baked NavMesh, check line of sight before firing, and patrol between waypoints.

Coins & exit

Collect every coin to open the exit door, then walk into the exit zone (tag END) to clear the level.

Clean state management

Singleton game manager for start, pause, game over, victory and level transitions.

03 Technical Details
