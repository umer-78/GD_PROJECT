Game Features

Procedural levels

Five levels, each carved at runtime with a recursive-backtracker. No two runs are guaranteed identical unless you fix the seed.

NavMesh enemies

Enemies pathfind on a baked NavMesh, check line of sight before firing, and patrol between waypoints.

Collectibles & traps

Coins to collect, power-ups to activate, and traps that reset your progress if you step on them.

Clean state management

Per-scene game manager: levels reset cleanly instead of leaking state between runs.
